# Games for My Blog Page

This project contains a collection of simple and interactive games created for my blog page. The games are designed to be easy to play, user-friendly, and accessible on different devices.

## Features

- Simple and attractive user interface
- Interactive gameplay
- Responsive design
- Easy to use and understand
- Lightweight and fast
- Suitable for desktop and mobile devices

## Games Included

- Tic-Tac-Toe
- Hidden Guess Game
- Odd or Even Game
- Treasure Hunt
- Tricky Pattern Game

## Technologies Used

- HTML5
- CSS3
- JavaScript
